# MtgScanner（Windows 版）

Web カメラで MTG のカードを読み取り、買取価格を出すアプリです。

## ダウンロード

**[MtgScanner-Setup.exe（最新版）](https://github.com/hinataku/MtgScanner-download/releases/latest/download/MtgScanner-Setup.exe)**

ダウンロードして実行するとインストールされます。過去の版は [Releases](https://github.com/hinataku/MtgScanner-download/releases) にあります。

## カメラが映らないとき

Windows の設定 → プライバシーとセキュリティ → カメラ で「デスクトップ アプリがカメラにアクセスできるようにする」がオンになっているか確認してください。
